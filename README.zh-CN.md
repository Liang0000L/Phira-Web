# Phira Web

这是一个独立的静态网页客户端，用于浏览和下载 Phira 谱面，以及查询账号相关数据。界面使用原生 HTML、CSS 和 JavaScript 模块构建，并由浏览器直接调用 Phira API。

**本项目不提供谱面游玩功能。** 本项目不是 Phira 官方产品，也不隶属于 TeamFlos。

[English](README.md)

## 功能

- 浏览、搜索、排序和筛选社区谱面，并查看热门谱面。
- 查看谱面详情、曲绘、元数据并下载谱面包。
- 查看单张谱面的前 15 条成绩，并切换标准分排序。
- 登录 Phira 账号并查看基本资料，包括账号 ID 和 RKS。
- 未登录时在本地保存收藏；登录后管理云端收藏夹。
- 在桌面和移动设备上使用响应式界面。

下载的谱面包供用户在本网站之外使用。网页不会解析谱面、播放音频、模拟成绩或提交成绩。

## 本地运行

无需构建步骤或安装依赖。请通过 HTTP 服务运行项目根目录；由于应用使用 JavaScript 模块并请求浏览器 API，不能直接通过 `file://` 打开 `index.html`。

使用 Python 3：

```sh
python3 -m http.server 8000
```

Windows 用户也可以运行：

```powershell
py -m http.server 8000
```

然后访问 <http://localhost:8000>。

## API 与部署

- API 主机：<https://phira.5wyxi.com>
- API 参考文档：<https://muimi.club/phira-api/>（社区维护的非官方文档）
- 项目不包含应用后端；API 请求由浏览器直接发起。
- API 必须通过 CORS 允许当前网站来源。静态前端无法绕过 CORS 限制；部署时可能需要 API 服务方允许部署域名。
- 谱面文件地址由 API 返回。根据文件托管服务和浏览器行为，下载可能在新标签页打开，也可能交由浏览器正常下载。
- 生产环境请使用 HTTPS，尤其是在登录功能启用时。

## 账号数据与隐私

登录时，浏览器会直接向 Phira API 发送凭证。返回的会话信息保存在浏览器本地存储中，以维持登录状态并发起需要认证的请求。退出登录会清除该会话。请勿在共享或不可信设备上登录。

未登录时的收藏同样保存在浏览器本地。本项目不包含自有服务器、账号数据库、分析或遥测功能。
